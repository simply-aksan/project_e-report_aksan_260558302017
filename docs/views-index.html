BAHAN PRAKTIK E-REPORT

Semua halaman. Siap jadi view.

14 halaman utama dan 4 contoh status tambahan. Tampilan mengikuti view proyek E-Report. Semua data merupakan ilustrasi. Tautan berpindah halaman; tombol login, simpan, hapus, dan perubahan status belum memiliki aksi.

Cara pakai saat mengajar

  1. Buka file HTML yang diperlukan di editor. Semua file dapat dibuka langsung di browser tanpa server.
  2. Untuk halaman warga/admin, cari komentar MULAI KONTEN HALAMAN dan AKHIR KONTEN HALAMAN . Salin isinya ke Blade halaman; kerangka sidebar dan header bisa dipindahkan ke layout.
  3. Tambahkan form, wire:model, wire:submit, route, dan data dinamis satu per satu saat praktik. Tombol saat ini memakai type="button".
  4. Salin folder assets untuk memakai CSS siap pakai. Class Tailwind tetap dipertahankan sesuai proyek; CSS ini mencakup class template yang sudah ada.
